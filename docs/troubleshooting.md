# 故障排查

当前没有公开安装包。以下步骤用于正式版本发布后的自助排查，不要求用户绕过 macOS 安全机制。

## 悬停后没有出现翻译卡片

1. 确认菜单栏中 Pointrans 已启用；
2. 确认按住的是当前设置的触发键，默认是左 Option；
3. 在系统设置中检查辅助功能权限；
4. 回到目标应用，重新按住触发键并停留片刻；
5. 尝试一段清晰、可选择的中文或英文文字。

如果只有某个应用无法识别，可能是该应用没有向辅助功能接口提供文字。

## 某些应用中无法读取文字

检查屏幕录制权限是否已授予。Pointrans 会在直接读取失败时使用本机 OCR 后备方案。

如果你不希望授予屏幕录制权限，可以继续在支持辅助功能文字读取的应用中使用，但部分场景无法识别。

## 刚授予权限仍然无效

macOS 有时需要目标应用重新启动后才应用新的隐私权限。退出 Pointrans 后重新打开，再检查菜单栏中的权限状态。

不要通过关闭系统完整性保护、修改隐私数据库或运行来源不明的命令强行授权。

## 翻译结果缺少语境

单词区用于快速查词；场景翻译用于理解周围片段。机器翻译仍可能误解指代、专业术语和省略语境。重要内容应人工复核。

## 下载文件无法验证

1. 停止安装；
2. 确认下载域名和 GitHub Release 均为官方入口；
3. 按[校验下载](./verify-download.md)核对 SHA-256；
4. 不要关闭 Gatekeeper 或修改系统安全策略；
5. 通过 Download Help 报告文件名、系统提示和脱敏截图。

## 仍然无法解决

请阅读 [SUPPORT.md](../SUPPORT.md)，再使用合适的 Issue 表单或 Q&A Discussion。不要上传包含私人文本的完整截图或日志。
