# 故障排查

当前没有公开安装包。以下内容是按已验收产品行为准备的发布后自助排查说明，不要求用户绕过 macOS 安全机制。

## 没有出现卡片

1. 确认菜单栏中光标翻译正在运行；
2. 确认辅助功能和屏幕录制两项权限都已授权；
3. 先把光标放进清晰英文单词或技术目标的字符范围；
4. 再按住当前触发键，默认是左 Option；
5. 松开后重新对准并按一次，不要按住后再移动到另一个目标。

按键瞬间会冻结坐标，每次按键只识别该坐标对应的目标。中文、其他文字、纯标点、空白、词间区域和不可信的 OCR 结果不会显示卡片，这属于预期行为。

## 某些应用中无法读取文字

即使辅助功能已经授权，部分应用也不会提供光标位置的可访问文字。光标翻译会在这类请求中使用屏幕录制权限，对附近小范围区域做本机 OCR。

当前版本要求两项权限都存在；不能把“只授予辅助功能”当作受支持的工作模式。实际截图仍只发生在主动触发且直接读取失败时，不会持续录屏。

## 刚授予权限仍然无效

退出光标翻译后重新打开，再检查菜单栏中的权限状态。macOS 有时要在应用重新启动后才应用新的隐私权限。

不要关闭系统完整性保护、修改隐私数据库或运行来源不明的命令强行授权。

## 技术目标没有普通词典结果

代码、路径、变量、简称、专业词汇或专有名称可能只显示分类，也可能同时显示已有词典义项。需要结合来源行理解时，可点击“AI 协助理解此处含义”。

AI 不是自动句子翻译。只有点击后才发送当前目标和最多 400 个字符的同一来源行文字，不发送截图。

## AI 解释不可用

正式下载发布前，生产 AI 服务还要完成审核。未来公开版本中如果 AI 请求失败，请确认网络可用后重试，并只在公开反馈中提供脱敏后的错误提示；不要粘贴原始来源行、凭据、完整请求或响应。

## 卡片松开按键后消失

这是正常交互。按住 Option 时卡片保留；若希望松开后继续查看，应先把光标移入卡片。移出卡片后会关闭。

## 下载文件无法验证

1. 停止安装；
2. 确认下载页面是 README 列出的官方入口；
3. 按[校验下载](./verify-download.md)核对 SHA-256；
4. 不要关闭 Gatekeeper 或修改系统安全策略；
5. 通过 Download Help 报告文件名、系统提示和脱敏截图。

## 仍然无法解决

请阅读 [SUPPORT.md](../SUPPORT.md)，再使用合适的 Issue 表单或 Q&A Discussion。不要上传包含私人文字的完整截图或日志。
