# 权限与数据说明

本页说明当前实现需要的 macOS 权限和数据边界。正式发布前必须以最终安装包、网络请求和隐私政策重新核对。

## 主动触发原则

Pointrans 只应在用户主动按住触发键并将光标停在文字上时，读取完成该次翻译所需的最少内容。菜单栏常驻不等于持续读取屏幕。

## 辅助功能

用途：读取光标位置由 macOS 辅助功能接口提供的文字。

- 在用户主动触发翻译时使用；
- 不用于记录键盘输入；
- 不用于控制其他应用；
- 撤销后，直接读取文字的能力不可用。

撤销方式：系统设置 → 隐私与安全性 → 辅助功能 → 关闭 Pointrans。

## 屏幕录制

用途：当辅助功能无法提供文字时，截取光标附近的小范围区域并使用 macOS 本机 OCR 识别。

- 只在主动触发且直接读取失败时使用；
- 当前实现中的截图在本机内存中处理；
- 当前实现不保存或上传 OCR 截图；
- 撤销后，OCR 后备方案不可用。

macOS 将这一权限统一称为“屏幕与系统录音”或“屏幕录制”，系统文案可能让权限范围显得比产品实际使用更大。

撤销方式：系统设置 → 隐私与安全性 → 屏幕与系统录音 → 关闭 Pointrans。

## 翻译文本

当前实现优先使用应用内置词典完成单词释义，并使用 macOS 系统翻译能力完成中英文片段翻译。系统可能按需管理语言资源。

当前公开说明不包含尚未发布的联网 AI 功能。如果未来版本将文本发送到 Pointrans 的生产服务或第三方 AI 服务，必须在发布前说明：

- 发送的数据类别；
- 处理目的和触发时机；
- 服务提供方与处理地区；
- 保留时间和日志策略；
- 关闭、退出和删除方式；
- 是否会用于模型训练。

## 产品分析与诊断

当前公开草案不承诺启用产品遥测。正式版本如采集安装、激活、留存、错误率或性能数据，必须做到：

- 不记录翻译原文、剪贴板历史、OCR 图像、完整提示词或完整输出；
- 在隐私政策中说明数据项目、用途、保留期和控制方式；
- 不用邮箱、GitHub 用户名或设备序列号作为分析标识；
- 将 CDN 和安全日志限制在必要范围内。
