# 常见问题

## 光标翻译是什么？

光标翻译是 Pointrans 面向简体中文用户的 macOS 菜单栏应用。先把光标放进英文目标，再按住 Option：普通英文词显示本地词典义项；代码、路径、变量、简称、专业词汇和专有名称显示分类卡片，并可点击“AI 协助理解此处含义”获取结合来源行文字的中文解释。

它不是自动全文翻译或句子翻译工具。

## Pointrans 是开源软件吗？

不是。本公开产品仓库用于产品介绍、未来下载、文档、版本说明和反馈，不包含产品源码，也未授予源码许可。

## 产品已经验收，为什么还不能下载？

当前 `0.1.0 (13)` 产品行为已经完成内部验收，但公开分发还要完成另一组工作：Developer ID 签名、苹果公证与 stapling、公开支持环境实机验证、生产 AI 服务审核，以及与最终安装包一致的正式隐私政策。

产品验收回答“功能是否符合预期”，公开发布审核回答“这个安装包和它连接的生产服务是否可以安全、稳定、透明地交给公众”。两者不能互相替代。

## 官网是提供下载的必要条件吗？

不是。满足公开发布条件后，可以先由本仓库的 GitHub Releases 提供安装包、SHA-256 和验证说明。官网或 CDN 以后上线时，同版本文件必须与 GitHub Release 字节一致。

拟定官网地址 `pointrans.cuostudio.com` 尚未验证可访问，目前不是下载入口。

## 支持哪些语言？

只支持英文→简体中文。当前版本不提供中文→英文、自动语言方向、句子翻译或全文翻译。

## 普通英文词从哪里获得释义？

普通查词使用随应用提供的只读 ECDICT 数据库，不需要联网。当前词典包含 390,573 条有效英中词条和 58,369 条词形映射，可把 `went`、`mice`、`better` 等常见词形回溯到对应原形。

## AI 是核心功能吗？会自动发送内容吗？

按需 AI 解释是核心能力之一，服务于代码、路径、变量、简称、专业词汇和专有名称等仅靠普通词典不容易理解的目标。但它不是自动全文或场景翻译：只有用户在分类卡片中点击“AI 协助理解此处含义”后才联网。

一次请求会发送当前目标和最多 400 个字符的同一来源行文字，不发送截图。当前设计没有单独的 AI 隐私开关；不点击按钮就不会发起 AI 请求。生产服务尚未达到公开发布条件，服务提供方、处理地区、保留策略和模型训练处理方式将以正式隐私政策为准。

## 是否需要自己配置 AI API Key？

公开版本不会要求用户提供第三方 AI 服务 API Key。生产版本必须通过 Pointrans 自有服务入口调用；是否需要登录及相关条款，将在正式 Release 和隐私政策中按最终产品事实说明，本页不提前承诺。

## 为什么需要辅助功能权限？

辅助功能用于在你主动按下触发键时读取光标精确覆盖的可访问字符和边界。当前版本缺少该权限时不会进入可用状态。

## 为什么还需要屏幕录制权限？

有些应用不会通过辅助功能接口提供目标文字。此时，光标翻译会截取光标附近的小范围区域，并使用 macOS 本机 OCR。当前已验收版本把屏幕录制列为必需权限，缺少该权限时同样不会进入可用状态。

这不表示应用持续录屏。截图只在用户主动触发且辅助功能读取失败时生成；像素只在本机内存中处理，不落盘、不上传。

## 默认如何触发？

先把光标放进英文目标的字符范围，再按住左 Option。可以改为右 Option；当前只支持左右两个 Option 键。按下时坐标会被冻结，每次按键只发起一个识别请求。

## 为什么有时完全不出现卡片？

卡片只在识别和查询成功后显示。中文、其他文字、纯标点、空白、词间区域和不可信的 OCR 结果不会先显示空卡片。

## 如何让卡片留下来？

按住 Option 时卡片保持显示。把光标移入卡片后可以松开按键，移出卡片时关闭；如果没有进入卡片，松开按键会立即关闭。

## 结果可以用于重要决定吗？

词典或 AI 解释都可能遗漏语境或产生错误。法律、医疗、财务、合同及其他高风险内容应由具备相应资格的人复核。

## macOS 提示应用无法验证怎么办？

当前没有公开安装包。正式发布后，请先确认文件来自 README 列出的官方入口并核对 SHA-256。我们不会要求用户关闭 Gatekeeper、修改系统安全策略或运行来源不明的终端命令。

## 可以提交功能建议吗？

可以。请描述具体场景、现在如何解决以及希望减少什么操作。建议进入讨论不代表已承诺开发或发布日期。
