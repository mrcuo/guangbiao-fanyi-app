# 常见问题

## Pointrans 是开源软件吗？

不是。本公开产品仓库用于下载、文档、版本说明和反馈，不包含产品源码，也未授予源码许可。

## 什么时候可以下载？

目前没有公开下载。首个公开安装包必须完成 Developer ID 签名、苹果公证、实机验证和隐私审核；如果版本包含联网 AI 功能，还必须先完成生产 AI 网关审核。

在这些条件完成前，不会提供需要用户绕过 macOS 安全机制的测试包。

## 为什么需要辅助功能权限？

Pointrans 使用辅助功能权限，在你主动按住触发键时读取光标位置可访问的文字。没有该权限时，大多数应用中的文字无法直接获取。

## 为什么还可能需要屏幕录制权限？

有些应用不会向辅助功能接口提供光标附近的文字。此时，Pointrans 可以对光标附近的小范围屏幕区域进行本机 OCR，因此需要 macOS 的屏幕录制权限。

当前实现不会为了翻译持续录制屏幕；OCR 图像只在本机内存中处理，不落盘、不上传。正式发布前会再次以发布安装包为准复核。

## 不授予屏幕录制权限可以使用吗？

可以使用能够通过辅助功能直接读取文字的场景；OCR 后备方案不可用，因此部分应用或内容可能无法识别。

## 默认如何触发翻译？

按住左 Option 键并将光标停在文字上。触发键可以在应用菜单中调整；公开版本的具体可选项以对应 Release 为准。

## 支持哪些语言？

当前实现面向中文和英文之间的查词与翻译。未来语言支持只有在正式 Release 中确认后才算公开能力。

## 是否需要账号或自己配置 API Key？

当前实现不要求账号，也不要求用户提供翻译服务 API Key。若未来加入联网 AI 能力，会在启用前更新隐私和数据说明。

## 翻译结果可以用于重要决定吗？

机器翻译可能遗漏语境或产生错误。法律、医疗、财务、合同及其他高风险内容应由具备相应资格的人复核。

## macOS 提示应用无法验证怎么办？

首先确认文件来自官方入口并核对 SHA-256。正式版本不要求关闭 Gatekeeper、修改系统安全策略或运行来源不明的终端命令。若验证失败，请使用 Download Help 提交已脱敏的信息。

## 可以提交功能建议吗？

可以。请描述具体场景、现在如何解决以及希望减少什么操作。建议进入讨论不代表已承诺开发或发布日期。
