## 它解决什么问题

阅读网页、文档、邮件和开发资料时，复制文字、打开翻译工具、粘贴再返回原页面，会不断打断注意力。Pointrans 希望把这个过程缩短为一次按键和悬停。

当前产品事实：

- 常驻 macOS 菜单栏，不占用 Dock；
- 默认按住左 Option 键，将光标停在文字上触发；
- 支持中文与英文之间的查词和场景翻译；
- 单词释义优先来自应用内置词典；
- 句子和片段翻译使用 macOS 系统翻译能力；
- 无法直接读取文字时，可在获得屏幕录制权限后对光标附近的小范围区域进行本机 OCR；
- 当前版本不要求用户提供翻译服务 API Key。

这里只列出已经实现并经过核对的能力。未发布的 AI 功能、价格、服务等级和发布日期不在本页承诺。

## 工作方式

1. 启动 Pointrans；
2. 按引导授予实际需要的系统权限；
3. 按住左 Option 键；
4. 将光标停在要理解的文字上；
5. 松开按键或移走光标，翻译卡片关闭。

Pointrans 会优先通过辅助功能读取光标附近的文字。只有无法直接读取时，才会请求屏幕录制权限并使用本机 OCR 识别光标附近的小范围内容。

## 权限与隐私

Pointrans 当前涉及以下系统权限：

| 权限 | 用途 | 没有该权限时 |
| --- | --- | --- |
| 辅助功能 | 在用户主动按住触发键时读取光标位置的可访问文字 | 无法直接读取大部分界面文字 |
| 屏幕录制 | 直接读取失败时，识别光标附近的小范围屏幕文字 | 无法使用本机 OCR 后备方案 |

当前实现中，OCR 图像仅在本机内存中处理，不落盘、不上传。应用不会为了翻译而持续录制屏幕，也不应读取与本次主动触发无关的后台内容。

正式发布前，以上说明仍需与最终安装包、网络请求和正式隐私政策逐项复核。若未来加入联网 AI 能力，将在启用前明确说明发送的数据、处理目的、服务提供方、保留时间和关闭方式。
