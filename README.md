# 光标翻译（Pointrans）

把光标放在英文目标上，按住 Option：普通英文词查看本地词典中文义项，代码、路径、变量、简称等可点击 AI 获取结合来源行的中文解释。

## 它解决什么问题

阅读网页、文档、邮件和开发资料时，频繁复制英文、打开翻译工具、粘贴再返回原页面，会打断注意力。光标翻译把普通查词缩短为“光标对准 + 按住 Option”。

本地英文查词与按需 AI 解释是当前已经验收的两项核心能力：

- 常驻 macOS 菜单栏，不占用 Dock；
- 只支持英文→简体中文，不提供中文→英文、自动语言方向或句子翻译；
- 普通英文词优先查询随应用提供的 ECDICT 只读词典，包含 390,573 条有效英中词条和 58,369 条词形映射；
- 代码、路径、变量、简称、专业词汇和专有名称会显示分类卡片；若词典中已有释义，也会一并显示；
- 分类卡片提供“AI 协助理解此处含义”，只有用户点击后才发起联网请求；
- 辅助功能无法读取目标时，对光标附近的小范围区域进行本机 OCR；
- 截图和 OCR 像素仅在本机内存中处理，不落盘、不上传。

产品没有反向词典、系统 Translation 框架、句子/上下文翻译区或“查看句中含义”。本仓库不会把尚未完成的价格、服务等级、开源计划或发布日期写成承诺。

## 工作方式

1. 先把光标准确放进英文单词或连续技术目标的字符范围；
2. 按住当前触发键——默认是左 Option，也可改为右 Option；
3. 按键瞬间会冻结光标坐标，每次按键只发起一次识别请求；
4. 识别和查询成功后才显示卡片，无效目标不会先闪出空白骨架；
5. 按住 Option 时卡片保持显示；如果光标已经进入卡片，可以松开按键，移出卡片后关闭；没有进入卡片时，松开按键即关闭。

中文、其他文字、纯标点、空白和词间区域不会显示卡片。

## 权限与隐私

当前已验收版本需要同时获得以下两项权限，缺少任一项时不会进入可用状态：

| 权限 | 用途 | 实际调用时机 |
| --- | --- | --- |
| 辅助功能 | 读取光标精确覆盖的可访问字符与边界 | 用户按下触发键后优先使用 |
| 屏幕与系统音频录制 | 在辅助功能无法读取时截取光标附近的小范围区域 | 仅在本次主动请求需要 OCR 后备时使用 |

屏幕录制权限是当前版本的必需权限，但这不表示应用持续录屏。截图只在用户主动触发且辅助功能读取失败时生成，像素仅在本机内存中处理，不保存、不上传。

普通词典查询完全使用随包资源。技术目标的 AI 解释只在用户点击“AI 协助理解此处含义”后请求；请求包含目标内容和最多 400 个字符的同一来源行文本，不包含截图。当前设计没有单独的 AI 隐私开关；不点击该按钮就不会发起 AI 请求。

生产 AI 服务尚未达到公开发布条件。服务提供方、处理地区、保留策略、是否用于模型训练等内容必须在正式隐私政策中按最终生产行为披露，在此之前不会发布带公开下载的版本。

请不要在公开 Issue 或 Discussion 中提交私人文字、账号、访问令牌、内部路径、未脱敏截图、完整日志或崩溃报告。详见[权限与数据说明](./docs/permissions-and-data.md)。
